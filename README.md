# Technology Comedy Club — IIT Kharagpur 🎭

Official website of the **Technology Comedy Club (TCC)** at IIT Kharagpur — where coding meets comedy!

🌐 **Live Site:** [snevj.github.io/ComC](https://snevj.github.io/ComC/)

---

## 📄 Pages

| Page | Description |
|---|---|
| Home | Welcome page with slideshow and club intro |
| Events | Past and upcoming events with hover effects |
| Photos | Interactive photo gallery |
| Contact | Governors and Advisors with LinkedIn links |
| About | Club history and aftermovie |

---

## 📁 Project Structure

```
ComC/
├── index.html          # Home page
├── about.html          # About page
├── contact.html        # Contact page
├── events.html         # Events page
├── photos.html         # Photos gallery
├── css/
│   ├── style.css       # Main stylesheet
│   ├── stylephotos.css # Photos page styles
│   └── styletabs.css   # Events page styles
└── images/             # All image assets
```

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome Icons
- Hosted on **GitHub Pages**

---

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Snevj/ComC.git
   ```
2. Open `index.html` in your browser — no setup needed!
